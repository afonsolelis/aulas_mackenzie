Regra da aula

Nenhum registro chega à camada de escrita sem passar por um contrato, e nenhuma rejeição desaparece sem registro.

Pydantic v2 · BaseModel

Contrato do livro extraído do HTML

class Livro(BaseModel):   # linha de bronze/books_toscrape/.../livros.jsonl
    upc: Annotated[str, Field(pattern=r"^[0-9a-f]{16}$")]
    url: HttpUrl
    titulo: Annotated[str, Field(min_length=1, max_length=500)]
    categoria: Annotated[str, Field(min_length=1)]
    avaliacao: Annotated[int, Field(ge=1, le=5)]
    preco_gbp: Annotated[Decimal, Field(gt=0, max_digits=8, decimal_places=2)]
    em_estoque: bool
    qtd_estoque: Annotated[int, Field(ge=0)]
    coletado_em: AwareDatetime
ConfigDict(extra="forbid") recusa campo novo. Um field_validator("preco_gbp", mode="before") tira o £ e recusa o texto com Â£, sinal de HTML decodificado com o charset errado.
Pydantic v2 · Coerção

Modo lax converte, modo strict recusa

EntradaLax (padrão)Strict
"23.5" para floataceita, vira 23.5recusa
"yes" para boolaceita, vira Truerecusa (bool_type)
"sim" para boolrecusa (bool_parsing)recusa
data sem fuso em AwareDatetimerecusa (timezone_aware)recusa
campo extra com extra="forbid"recusa (extra_forbidden)recusa
Strict por modelo: ConfigDict(strict=True); por campo: Field(strict=True); por chamada: model_validate(dados, strict=True).
Pydantic v2 · Regras

Validadores de campo e de modelo

class LeituraBruta(BaseModel):          # mensagem da Aula 06
    event_id: UUID
    device_id: DeviceId                  # estufa-a-03, germinacao-01
    medido_em: AwareDatetime
    temperatura: float
    unidade_temperatura: Literal["C", "F"]
    umidade: float = Field(ge=0, le=100)
    @model_validator(mode="after")
    def regras_da_aula_06(self, info): ...   # faixa em °C e medido_em no futuro
field_validator olha um campo; model_validator vê o objeto inteiro: converte F para °C antes de aplicar a faixa. normalizar() gera a linha de iot.leituras com temperatura_c e umidade_pct.
Pydantic v2 · Erros

Registrar o erro de cada registro

for posicao, corpo in enumerate(corpos):
    try:
        bruta = LeituraBruta.model_validate_json(corpo, context={"agora": agora})
    except ValidationError as erro:
        erros = erro.errors(include_url=False, include_context=False)
        rejeitadas.append({"posicao": posicao, "motivo": motivo(erros),
                           "payload": corpo.decode(), "erros": erros})
        continue
    validas.append(bruta.normalizar(cadastro))
motivo() traduz o erro para os códigos da Aula 06 (unidade_desconhecida, umidade_fora_da_faixa...). Cada erro traz loc, type, msg e input. TypeAdapter(list[CotacaoPtax]) valida listas; model_json_schema() publica o contrato.

Testes · VCR

Gravar a resposta HTTP real uma vez

@pytest.fixture(scope="module")
def vcr_config():
    return {"filter_headers": ["authorization", "cookie", "set-cookie"],
            "decode_compressed_response": True}
@pytest.mark.vcr
def test_ptax_cabe_no_contrato():
    resposta = buscar_ptax("GBP", date(2026, 10, 2))
    cotacoes = ListaPtax.validate_python(resposta["value"])
    assert cotacoes[-1].tipo_boletim == "Fechamento PTAX"
Padrão do pytest-recording: modo none, só reproduz. --record-mode=once grava o cassete que falta; --record-mode=rewrite regrava de propósito; --block-network prova que nada saiu para a rede.
Testes · VCR

O cassete congela a fonte no dia da gravação

O cassete congela a resposta do dia da gravação. Se a API mudar, o teste segue verde e a produção quebra.

Regravar quando

o contrato mudar, a fonte anunciar versão nova, o cassete passar da idade definida na spec ou a produção registrar rejeição nova.

Proteger com

teste de contrato agendado contra a API real, data de gravação no nome do cassete e revisão do diff do YAML no PR.

Testes · Testcontainers

MinIO real num contêiner descartável

from testcontainers.community.minio import MinioContainer
IMAGEM_MINIO = "coollabsio/minio:RELEASE.2025-10-15T17-29-55Z"
@pytest.fixture(scope="session")
def minio():
    container = MinioContainer(image=IMAGEM_MINIO)
    container.with_env("MINIO_ROOT_USER", container.access_key)
    container.with_env("MINIO_ROOT_PASSWORD", container.secret_key)
    with container:
        yield container
Mesma ideia para RabbitMqContainer, ClickHouseContainer e PostgresContainer, sempre com tag fixa.
