Construção do conteúdo · Problema

O que a previsão dizia às 10h de terça?

A API de previsão devolve sempre a previsão vigente. Quem não gravou a resposta às 10h não consegue reconstruí-la depois.

Resultado observável da aula

Seis capitais coletadas a cada hora, cada resposta gravada como JSON bruto no bucket raw, com chave previsível, metadados de origem e nenhuma duplicata quando o coletor roda de novo.

Conceito

Cinco decisões tomadas no primeiro dia

As escolhas do primeiro dia são caras de mudar quando o bucket tiver milhões de objetos.

  1. Onde: qual tipo de armazenamento recebe o dado.
  2. Com que nome: a chave define quais leituras serão baratas.
  3. Em que formato: bytes da fonte ou dado já transformado.
  4. Com que procedência: quando, de onde, por qual versão do coletor.
  5. Se rodar duas vezes: duplica ou mantém o mesmo estado.

Object storage por dentro

Bucket, chave, objeto e metadados

Bucket

Contêiner com nome único; recebe política de acesso, versionamento e ciclo de vida.

Chave

Uma string. A barra é só um caractere; listar por prefixo simula pastas.

Objeto

Imutável: mudar um byte significa regravar o objeto inteiro.

Metadados

Cabeçalhos x-amz-meta-*, lidos com HEAD; valores em ASCII.

Object storage por dentro

Consistência, versionamento e ciclo de vida

Consistência

MinIO documenta leitura e listagem após escrita estritas (em XFS, ZFS, Btrfs). Um HEAD após PUT confirmado encontra o objeto.

Versionamento

Cada gravação na mesma chave vira uma versão. Aqui, também detecta falha de idempotência.

Ciclo de vida

Regras expiram objetos ou versões antigas por prefixo e por dias.

mc version enable local/raw
mc ls --recursive --versions local/raw/open_meteo/
mc ilm rule add --noncurrent-expire-days 7 local/raw
Camada raw

Chave particionada no estilo Hive

A chave diz a fonte, o dia e a hora da coleta e a cidade. DuckDB e Spark leem data e hora como colunas.

bucket: raw
open_meteo/data=2026-10-17/hora=12/sao_paulo.json
open_meteo/data=2026-10-17/hora=12/manaus.json
_manifestos/open_meteo/data=2026-10-17/hora=12/execucao_20261017T120431Z.jsonl
Decisões embutidas

Partição pelo momento da coleta, em UTC. Cidade como identificador ASCII estável. Manifesto em JSON Lines fora do prefixo de dados.

Camada raw

Imutabilidade, idempotência e procedência

Imutável

Grava os bytes recebidos. Sem limpar, renomear ou reserializar.

Idempotente

HEAD antes do PUT. Se a chave existe, não grava e registra ja_existia.

Rastreável

fonte, coletado-em, versao-coletor, sha256, cidade e coordenada pedida.

Por que importa no Railway

O proxy devolve 502 esporádico. Com chave determinística, repetir a gravação é seguro; com chave por horário em segundos, cada retry duplica.

A fonte

API de previsão da Open-Meteo, sem chave

Uso não comercial: menos de 10.000 chamadas por dia e licença CC BY 4.0. Seis capitais por hora somam 144 chamadas por dia.

curl -s "https://api.open-meteo.com/v1/forecast?latitude=-23.55&longitude=-46.63&hourly=temperature_2m,relative_humidity_2m&timezone=America/Sao_Paulo&forecast_days=1"

# parâmetro inválido: HTTP 400 com {"error": true, "reason": "..."}
# resposta traz a coordenada da grade: -23.514938, -46.610504

Verificação local

Rodar duas vezes e contar objetos

set -a; source .env; set +a
python -m pytest -q
python -m src.coletor && python -m src.coletor
docker compose exec -T minio mc find local/raw/open_meteo --name "*.json" | wc -l
docker compose exec -T minio mc ls --recursive --versions local/raw/open_meteo/ | wc -l
docker compose exec minio mc stat local/raw/open_meteo/data=2026-10-17/hora=12/sao_paulo.json
docker compose exec -T minio mc cat local/raw/open_meteo/data=2026-10-17/hora=12/sao_paulo.json | sha256sum

Contagens iguais antes e depois da segunda execução. Hash do conteúdo igual ao metadado sha256.

MinIO do Railway

Mesmo coletor apontado para o Railway

.env.railway fora do Git; o mc pede as chaves de forma interativa.

docker compose exec minio mc alias set railway https://<dominio-da-porta-9000>
docker compose exec minio mc mb --ignore-existing railway/raw
docker compose exec minio mc version enable railway/raw
set -a; source .env.railway; set +a
python -m src.coletor && python -m src.coletor
docker compose exec -T minio mc find railway/raw/open_meteo --name "*.json" | wc -l
docker compose exec minio mc du railway/raw
