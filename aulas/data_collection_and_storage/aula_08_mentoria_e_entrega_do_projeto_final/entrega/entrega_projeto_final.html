Antes de enviar

  • A entrega é individual. Para corrigir algo, envie de novo com o mesmo nome: vale o envio mais recente feito até o prazo.
  • O repositório precisa ser público. O professor avalia o último commit do ramo main feito até o prazo.
  • O repositório precisa conter o coletor, a construção da silver e da gold, o dashboard, os testes, os artefatos de SDD (AGENTS.md, docs/ e specs/), a matriz de rastreabilidade, o histórico de prompts e o README que permite rodar o projeto do zero. A lista completa está na página do projeto.
  • Não coloque no repositório arquivos .env, senhas, chaves de API nem credenciais do Railway. Faça a busca de segredos da seção 12 do enunciado antes de enviar.
