Conexão dados

Tudo o que o grupo precisa para se conectar, nesta aula, aos dois serviços da turma que rodam na VPS: o ClickHouse, com o banco mackenzie da Aula 05, e o RustFS, o object storage compatível com S3. Os dois estão no ar com HTTPS na porta 443, então funcionam do Codespace, do notebook ou do navegador, sem Docker e sem VPN.

Python com clickhouse-connect

Para notebooks e scripts que precisam devolver DataFrame. Instale com pip install clickhouse-connect pandas.

import clickhouse_connect

ch = clickhouse_connect.get_client(
    host="clickhouse.afonsolelis.tech",
    port=443,
    secure=True,
    username="turma",
    password="sRwz6u2W6OQKkQgHlDwP",
    database="mackenzie",
)
print(ch.query("SELECT currentUser(), version()").result_rows)
df = ch.query_df("SELECT data_tag, count() AS linhas FROM db_ingestion GROUP BY data_tag")
print(df)

Python com boto3

Instale com pip install boto3.

s3 = boto3.client(
    "s3",

    aws_access_key_id="turma-mackenzie",
    aws_secret_access_key="Mack5fb631Dados2026",
    region_name="us-east-1",
    config=Config(s3={"addressing_style": "path"}),
)
print([b["Name"] for b in s3.list_buckets()["Buckets"]])
print(s3.list_objects_v2(Bucket="pouso", MaxKeys=5)["Contents"][0]["Key"])

SELECT filename, content FROM read_text('s3://pouso/CAM-0451_20261017T0900.txt');

O ClickHouse da turma não lê o RustFS com a função s3(): o usuário turma não tem essa permissão. Para levar um arquivo do RustFS ao ClickHouse, baixe com boto3 e insira pelo rodar_sql.py ou pelo clickhouse-connect.

3. Se não conectar

SintomaCausa provável
Authentication failed no ClickHousesenha copiada com espaço ou aspas; confira o .env
ACCESS_DENIED no ClickHouseobjeto fora do banco mackenzie; sempre qualifique como mackenzie.gNN_...
SignatureDoesNotMatch no RustFSregião diferente de us-east-1 ou endereço virtual-host; use path-style
timeout nas portas 8123, 9000 ou 9440só a 443 está aberta; use HTTPS
