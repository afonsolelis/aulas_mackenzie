Data Collection and Storage · MBA Engenharia de Dados

Aula 03 — Coleta e Armazenamento de Dados Não Estruturados e Semi-estruturados

24/10/2026 · Sábado · 8h30 – 12h10

1. Visão Geral e Contextualização

Processamento de JSON, XML, imagens e documentos, com otimização de formatos colunares.

No ecossistema de Engenharia de Dados moderna, garantir uma estratégia robusta de coleta e armazenamento é o primeiro e mais crítico passo para a confiabilidade de qualquer plataforma de analytics ou Inteligência Artificial.

2. Conceitos Teóricos e Arquitetura (8h30 – 9h30)

Formatos de Arquivos (JSON vs Parquet vs ORC vs Avro), Compressão (Snappy/Gzip), Particionamento de Storage por Data e Categoria.

A arquitetura de coleta deve considerar volumetria, frequência, tolerância a falhas e schema evolution para evitar gargalos operacionais no Data Lake.

3. Laboratório Prático no AWS Student Lab (9h30 – 12h10)

Laboratório 03: Transformação e Particionamento no Amazon S3

Objetivo: Implementar na prática o fluxo de captura e armazenamento utilizando os recursos da AWS.

  1. Acesse o ambiente AWS Academy Learner Lab e inicie a sessão do console AWS em us-east-1.
  2. Execute a atividade prática conforme os passos descritos: Conversão de arquivos JSON volumosos para Apache Parquet usando PySpark/DuckDB e consulta interativa com AWS Athena..
  3. Valide a gravação dos dados no Amazon S3 / DynamoDB e confirme os metadados.

Atividade Prática em Sala

Este curso é 100% prático. Conclua o laboratório no AWS Student Lab durante o horário de aula (sábados de manhã) e valide o funcionamento dos pipelines no console AWS.
